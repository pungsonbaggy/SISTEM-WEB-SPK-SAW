# Sistem Pendukung Keputusan Pemilihan Destinasi Wisata Bahari Kabupaten Pesawaran

Repositori ini berisi kode sumber untuk Tugas Akhir/Skripsi dengan judul **"Sistem Pendukung Keputusan Pemilihan Destinasi Wisata Bahari Kabupaten Pesawaran Berdasarkan Profil Wisatawan Menggunakan Metode Simple Additive Weighting (SAW)"**.


## Deskripsi Singkat
Sistem ini dirancang untuk membantu para wisatawan dalam memilih destinasi wisata bahari di Kabupaten Pesawaran yang paling sesuai dengan profil dan preferensi mereka. Sistem menggunakan metode **Simple Additive Weighting (SAW)** untuk melakukan pembobotan dan perangkingan kriteria, sehingga menghasilkan rekomendasi destinasi yang objektif.
